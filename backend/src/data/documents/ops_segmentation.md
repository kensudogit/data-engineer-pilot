# 顧客分類モデル 運用ノート

## 概要

RFM（Recency/Frequency/Monetary）指標をもとに顧客を4クラスタへ分類するモデルです。BigQuery MLではKMEANS（`num_clusters=4`）、Snowflakeでは（Cortex ML Functionsにクラスタリング用の組み込み関数がないため）Snowpark MLのKMeans、デモ経路ではscikit-learnのKMeansを使用します。

## クラスタラベルの付け方

クラスタは平均購買額（monetary_90d）の高い順に「VIP → 優良顧客 → 一般顧客 → 休眠リスク」と一意にラベル付けされます。これは閾値ベースのルール（例: recency_rankが3以上なら休眠リスク）ではなく、ランク方式を採用しています。閾値ベースのルールは複数クラスタが同じラベルになってしまう不具合が過去に発生したため、意図的にランク方式へ変更した経緯があります。

## クラスタ別の一般的な施策の目安

- **VIP**: 優先サポート・限定オファーの対象
- **優良顧客**: アップセル・クロスセルの主要ターゲット
- **一般顧客**: 定期的な利用促進コミュニケーション
- **休眠リスク**: 再エンゲージメント施策（休眠復帰キャンペーン等）の対象

## 精度指標の見方

シルエットスコアを画面上部に表示しています。-1〜1の範囲で、1に近いほどクラスタ間の分離が明確であることを示します。seed=42の合成データでは約0.46前後です。
